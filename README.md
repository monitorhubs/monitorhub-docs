# Monitor Hub Documentation

Official documentation, setup guides, API references, and integration tutorials for Monitor Hub.

Monitor Hub helps developers, DevOps teams, agencies, and businesses monitor website uptime, API health, server infrastructure, incidents, and service status from one platform.

### Server Monitoring
- Windows and Linux Server Telemetry
- Agent Installation and Configuration

### Alerts and Incident Management
Monitor Hub supports configurable alerting through available integrations, including:

- Email
- Telegram
- Slack
- Discord
- Webhooks

See the [Documentation Hub](https://monitorhubs.com/docs) for setup instructions and supported integration details.

### Status Pages and Reporting
- Public Status Pages
- White-Label Status Pages and Custom Domains
- Incident History and Reporting
- Uptime and SLA Reporting

Explore [White-Label Status Pages](https://monitorhubs.com/status-pages) for branded service-status publishing.

### AI Integrations and Model Context Protocol (MCP)
Monitor Hub provides a remote MCP integration for compatible AI clients to access supported monitoring capabilities.

- **MCP endpoint:** https://mcp.monitorhubs.com/mcp
- **MCP Technical Guide:** https://monitorhubs.com/docs/remote-mcp
- **AI and Integration Guides:** https://monitorhubs.com/docs/guides

Refer to the MCP guide for current client compatibility, authentication, available tools, permissions, and connection instructions.
